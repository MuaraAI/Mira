# Mira v3.5.0

## Perbaikan utama

### Login MyBest: CAPTCHA diselesaikan otomatis dengan OCR

CAPTCHA MyBest kini dibaca otomatis oleh OCR di server saat login dan saat sesi kampus perlu dipulihkan. Pengguna cukup masuk dengan NIM dan password MyBest.

Pada pengujian 47 CAPTCHA MyBest, 32 kode diterima kampus, 15 percobaan tertahan throttle kampus, dan tidak ada kode yang ditolak sebagai CAPTCHA salah. Angka ini merangkum hasil pengujian tersebut.

### Perbaikan login dan sesi kampus

- ddddocr menjadi OCR utama; Tesseract hanya dipakai sebagai fallback.
- Setiap percobaan login memakai CAPTCHA baru. Backend berhenti mencoba jika kampus menolak karena alasan selain CAPTCHA.
- Cookie sesi kampus diterapkan konsisten agar proses login tidak memakai cookie lama.
- Sesi kampus diperbarui saat diperlukan, bukan melalui login proaktif berkala.
- Password SIAKAD tidak lagi ditebak dari password MyBest.

## Fitur dan perbaikan lain

### SIAKAD opsional

- SIAKAD dapat ditautkan atau dilepas dari halaman **Sesi & Keamanan** menggunakan password SIAKAD.
- Halaman KRS, KHS per semester, jadwal ujian, dan soal ujian offline menampilkan data SIAKAD setelah akun ditautkan.
- Status tautan dan sisa masa sesi kampus tampil di halaman Sesi & Keamanan.
- Cache profil dan parser lama dipisahkan agar data pribadi profil tidak ikut tersaji.

### Dashboard dan MyBest

- Kartu IPK memakai data KHS.
- Jadwal “hari ini” mengambil nama hari dari judul bagian MyBest; dashboard memakai satu sumber jadwal.
- Kartu Flexing membuat gambar PNG dari nilai tugas MyBest yang sudah dinilai dosen.
- Informasi TOEFL tersedia melalui endpoint MyBest.
- Notifikasi diperbaiki agar tidak berulang untuk kegiatan yang sama; kuis yang sudah lewat tidak lagi dianggap aktif.

## Catatan API

- `POST /v1/auth/login` memakai NIM dan `elearning_pass`; CAPTCHA diselesaikan server.
- SIAKAD dihubungkan terpisah melalui `POST /v1/auth/credentials` dan dilepas melalui `DELETE /v1/auth/credentials/siakad`.
- `GET /v1/auth/me` memuat sisa masa sesi dan status tautan sistem.
- `GET /v1/studentv2/khs-semester?semester=N` menyajikan KHS per semester dan IPS.
