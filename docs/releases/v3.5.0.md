# Mira v3.5.0

> Draft release notes.

## Mira makin mudah diakses

Login MyBest kini ditangani lebih praktis: OCR membaca CAPTCHA otomatis di server, sementara SIAKAD dapat ditautkan terpisah dari halaman Sesi & Keamanan. Dashboard juga menampilkan data akademik kampus dan status sesi dengan lebih jelas.

## Sorotan

- **Login MyBest dengan OCR CAPTCHA.** Server memakai ddddocr untuk membaca CAPTCHA, dengan Tesseract sebagai fallback. Dalam 47 percobaan uji MyBest, 32 kode diterima kampus, 15 percobaan tertahan throttle, dan tidak ada kode yang ditolak sebagai CAPTCHA salah.
- **SIAKAD terhubung sesuai pilihan pengguna.** Login Mira memakai NIM dan password MyBest. Hubungkan SIAKAD secara terpisah di Sesi & Keamanan dengan password SIAKAD.
- **Data akademik SIAKAD di dashboard.** Lihat KRS, KHS per semester beserta IPS, dan jadwal serta soal ujian UTS/UAS. Halaman terkait menyediakan langkah untuk menautkan SIAKAD jika belum terhubung.
- **Status sesi kampus.** Halaman Sesi & Keamanan menampilkan sisa masa sesi dan status tautan MyBest maupun SIAKAD.
- **Privasi profil SIAKAD.** Profil hanya memuat field akademik yang diizinkan. Cache profil lama dipisahkan agar data pribadi yang pernah tersimpan tidak ikut tersaji.
- **Jadwal dan nilai lebih akurat.** Jadwal “hari ini” membaca hari dari judul seksi MyBest, dashboard memakai satu sumber jadwal, dan kartu IPK menampilkan data KHS.
- **Notifikasi dan Flexing.** Perbaikan deduplikasi notifikasi, ringkasan berita harian, dan filter kuis yang sudah lewat. Studio Flexing di halaman Nilai & KHS membuat kartu PNG dari nilai tugas MyBest yang sudah dinilai dosen.
- **TOEFL MyBest.** Informasi TOEFL kini tersedia melalui endpoint API.
- **Perbaikan sesi dan login.** Cookie sesi kampus diterapkan konsisten, pemulihan sesi berjalan saat dibutuhkan, dan cache SIAKAD dibuang setelah sesi ditolak.

## Perubahan API

- `GET /v1/studentv2/khs-semester?semester=N` menyajikan KHS per semester beserta IPS.
- `GET /v1/auth/me` menyertakan sisa masa sesi serta status tautan MyBest dan SIAKAD.
- SIAKAD dikelola terpisah melalui endpoint kredensial; password MyBest tidak otomatis digunakan untuk login SIAKAD.
- Cache kursus memakai versi baru agar data dari format parser lama tidak tercampur.

## CAPTCHA SIAKAD

OCR CAPTCHA SIAKAD berhasil dipakai pada verifikasi login langsung. SIAKAD tetap ditautkan secara terpisah dengan kredensial kampus.
