# API Reference

UBSI API organizes all endpoints under the `/v1/` prefix. Every endpoint returns a standardized Clean Minimalist JSON envelope.

---

## Response Envelope Format

### Successful Response (`200 OK`)
```json
{
  "success": true,
  "data": [...],
  "cached": false
}
```
*Note: When served from the Last-Known-Good fallback cache during upstream outages, an additional field `"stale": true` is included.*

### Error Response (`4xx` / `5xx`)
```json
{
  "success": false,
  "error": {
    "code": "UPSTREAM_TIMEOUT",
    "message": "Deskripsi kesalahan teknis",
    "module": "elibrary"
  }
}
```

## Authentication & Dual-Mode Access

UBSI API supports two operating modes:

### 1. Standalone / Self-Host Mode (Default)
Run locally or on your own VPS with a single master key:
- Header: `X-API-Key: <your_master_key>`
- Developer overrides supported per-request via headers: `X-Studentv2-NIM`, `X-Studentv2-Pass`, `X-Elearning-NIM`, `X-Elearning-Pass`.
- Rate limiting: Unlimited for Master Key.

### 2. Cloud Hosted Mode (Muara AI Platform)
Deployed on `api.muaraai.com` or `ubsi-api.muaraai.com` with multi-tenancy:
- Login BSI di dashboard (`ubsi-api.muaraai.com/login`) dengan NIM + password kampus.
- Session token (Redis, TTL 7 hari sliding) dikirim via cookie `ubsi_session` atau header `Authorization: Bearer <token>`.
- Backend meng-inject kredensial kampus dari session ke setiap request (tidak ada kredensial di disk).
- Rate limiting: 60 requests/minute per session.

### API Gateway Prefix (`ROOT_PATH`)
When proxied behind an API Gateway (e.g., Caddy handling `api.muaraai.com/v1/ubsi-api/*`), set `ROOT_PATH=/v1/ubsi-api` in `.env`. Swagger UI (`/docs`) and OpenAPI schema automatically adjust to the sub-path prefix.

### `POST /v1/auth/verify`
Pre-validation endpoint to verify that student credentials actually authenticate against both campus portals (`students.bsi.ac.id` and `elearning.bsi.ac.id`). Dipakai juga oleh `POST /v1/auth/login` (via `verify_live_credentials`).
- **Access**: Master Key Only (`request.state.is_master == True`). Key tidak dikenal return `401 UNAUTHORIZED`.
- **Rate Limit**: Max 5 requests/minute per NIM (sliding-window anti-brute-force protection).
- **Request Body**:
  ```json
  {
    "nim": "15260767",
    "elearning_pass": "mybest_password",
    "studentv2_pass": "siakad_password"
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "data": {
      "valid": true,
      "nim": "15260767",
      "elearning": { "valid": true, "message": null },
      "studentv2": { "valid": true, "message": null }
    }
  }
  ```

### `POST /v1/auth/login`
Authenticates student credentials live against both SIAKAD and MyBest portals, creates an in-memory session in Redis (sliding 7 days TTL), and issues a session cookie `ubsi_session` plus bearer token.
- **Access**: Public
- **Rate Limit**: Max 5 requests/minute per NIM.
- **Request Body**:
  ```json
  {
    "nim": "15260767",
    "studentv2_pass": "siakad_password",
    "elearning_pass": "mybest_password"
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "data": {
      "nim": "15260767",
      "token": "ubsi_sess_random_token_32B",
      "message": "Login berhasil. Session aktif 7 hari (sliding)."
    }
  }
  ```

### `POST /v1/auth/logout`
Terminates the current device session and clears the session cookie and Redis key.
- **Access**: Session Token Required (`Authorization: Bearer <token>` or cookie `ubsi_session`).

### `POST /v1/auth/logout_all`
Terminates all active sessions across all devices for the authenticated student.
- **Access**: Session Token Required.

### `GET /v1/auth/me`
Retrieves authentication state for the calling client. Returns NIM for student session tokens or identity `master` for Master Key.
- **Access**: Session Token or Master Key.

### `GET /v1/auth/keys`
Lists all Personal API Keys (`muara_ubsi_***`) generated by the authenticated student (maximum 5 keys).
- **Access**: Session Token Required.
- **Response**:
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "key_1",
        "name": "Hermes Agent Key",
        "key_prefix": "muara_ubsi_b854...",
        "created_at": "2026-10-18T10:00:00"
      }
    ]
  }
  ```

### `POST /v1/auth/keys`
Generates a new Personal API Key for connecting AI Agents (Claude Code, Cursor, Codex, Hermes) or custom scripts without exposing campus passwords.
- **Access**: Session Token Required.
- **Request Body**:
  ```json
  {
    "name": "Cursor IDE Academic Key"
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "data": {
      "id": "key_2",
      "name": "Cursor IDE Academic Key",
      "key": "muara_ubsi_abcdef1234567890abcdef1234567890",
      "message": "Simpan kunci ini sekarang. Kunci ini tidak dapat ditampilkan kembali."
    }
  }
  ```

### `DELETE /v1/auth/keys/{key_id}`
Revokes a Personal API Key.
- **Access**: Session Token Required.

## 2. StudentV2 (SIAKAD)

All StudentV2 endpoints require active student authentication (session login, personal API key `muara_ubsi_***`, or developer headers `X-Studentv2-NIM` & `X-Studentv2-Pass`).

### `GET /v1/studentv2/dashboard`
Retrieves course schedule, raw grades, news, and circular announcements in parallel within a single request.
- **Cache**: Re-uses existing fresh cache per section; section failure does not break the entire response.
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": {
      "schedule": [...],
      "grades": [...],
      "news": [...],
      "announcements": [...]
    },
    "cached": false
  }
  ```

### `GET /v1/studentv2/schedule`
Retrieves the official course schedule for the active semester.
- **Cache TTL**: 2 hours (7200 seconds)
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "e0a17f300c3b",
        "kode": "104",
        "nama": "BAHASA INGGRIS I",
        "hari": "Selasa",
        "jam": "09:10-10:50",
        "sks": 2,
        "kelompok_praktek": null,
        "ruang": "EN2-P1",
        "kode_dosen": "TDL"
      }
    ],
    "cached": false
  }
  ```

### `GET /v1/studentv2/grades`
Retrieves raw semester grades including UTS, UAS, assignments, attendance, total score, and final letter grade.
- **Cache TTL**: 30 minutes (1800 seconds)
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "c104",
        "kode": "104",
        "nama": "BAHASA INGGRIS I",
        "sks": 2,
        "uts": 85.0,
        "uas": 90.0,
        "tugas": 88.0,
        "absen": 100.0,
        "total": 89.5,
        "grade": "A"
      }
    ],
    "cached": false
  }
  ```

### `GET /v1/studentv2/news`
Archives of official student circulars and news announcements.
- **Parameters**: `limit` (default: 50, max: 200)
- **Cache TTL**: 15 minutes (900 seconds)

### `GET /v1/studentv2/announcements`
Latest internal announcements and PDF notices displayed on the student portal dashboard.
- **Cache TTL**: 15 minutes (900 seconds)

### `GET /v1/studentv2/profile`
Retrieves student personal bio, study program, active semester, and academic status from SIAKAD.
- **Cache TTL**: 1 hour (3600 seconds)

### `GET /v1/studentv2/khs`
Retrieves semester study results (KHS) including course letter grades, total credit points (mutu), total SKS, and cumulative GPA (IPK).
- **Cache TTL**: 30 minutes (1800 seconds)

### `GET /v1/studentv2/krs`
Retrieves active study plan card (KRS), list of enrolled courses, exam group, and total semester SKS.
- **Cache TTL**: 2 hours (7200 seconds)

### `GET /v1/studentv2/uts`
Retrieves midterm exam room info, online exam schedule link, and offline question download URLs.
- **Cache TTL**: 2 hours (7200 seconds)

### `GET /v1/studentv2/uas`
Retrieves final semester exam (UAS) room info, online exam schedule link, and offline question download URLs.
- **Cache TTL**: 2 hours (7200 seconds)

### `GET /v1/studentv2/calendar`
Retrieves the official academic calendar PDF download URL for the current academic year.
- **Cache TTL**: 1 hour (3600 seconds)

### `GET /v1/studentv2/prodi-contacts`
Retrieves official directory of 51 email contacts of Faculty Deans and Heads of Study Programs (Kaprodi) across all UBSI campuses.
- **Cache TTL**: 1 hour (3600 seconds)

### `GET /v1/studentv2/certificates`
Retrieves student certificate records (Course, TOEFL, LSP, seminar) from SIAKAD.
- **Cache TTL**: 1 hour (3600 seconds)

### `GET /v1/studentv2/lecturers`
Searchable directory of 1,350+ lecturers with initials code and full name.
- **Query Parameter**: `search` (optional)
- **Cache TTL**: 1 hour (3600 seconds)

## 3. Elearning (MyBest LMS)

All Elearning endpoints require active student authentication (session login, personal API key `muara_ubsi_***`, or developer headers `X-Elearning-NIM` & `X-Elearning-Pass`).

### `GET /v1/elearning/courses`
Lists enrolled LMS courses with schedule metadata and encrypted action tokens.
- **Cache TTL**: 10 minutes (600 seconds)
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "c101",
        "kode": "101",
        "nama": "PENDIDIKAN PANCASILA",
        "sks": 2,
        "kode_dosen": "BDM",
        "kelompok_praktek": null,
        "kode_gabung": "KG.101.30.C",
        "jadwal": {
          "hari": "Jumat",
          "jam": "07:30-09:10",
          "ruang": "EL2-P1"
        },
        "tokens": {
          "absen": "eyJpdi...",
          "diskusi": "eyJpdi...",
          "learning": "eyJpdi...",
          "assignment": "eyJpdi..."
        },
        "token_absen": "eyJpdi...",
        "token_assignment": "eyJpdi...",
        "token_learning": "eyJpdi...",
        "token_diskusi": "eyJpdi..."
      }
    ],
    "cached": false
  }
  ```

### `GET /v1/elearning/assignments`
Retrieves active assignment requirements, deadlines, and graded submission history.
- **Query Parameter**: `token` (optional; when omitted, aggregates all active assignments across all courses)
- **Cache TTL**: 10 minutes (600 seconds)

### `POST /v1/elearning/assignments/upload`
Submits/uploads student assignment submission file (PDF, DOCX, ZIP, etc.) to MyBest LMS.
- **Payload**:
  ```json
  {
    "token_tugas": "tok_upload_123",
    "filename": "tugas_p5_15260767.zip",
    "file_base64": "base64_encoded_file_bytes",
    "catatan": "Keterangan tugas opsional"
  }
  ```

### `POST /v1/elearning/assignments/submit`
Submits or updates student assignment URL link (Google Drive / GitHub) directly to MyBest.
- **Payload**:
  ```json
  {
    "token_send": "eyJpdi...",
    "link_tugas": "https://drive.google.com/file/d/14wUrOkCVbx..."
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "data": {
      "status": "success",
      "message": "Tugas berhasil dikumpulkan ke MyBest",
      "link_tugas": "https://drive.google.com/file/d/14wUrOkCVbx..."
    }
  }
  ```

### `GET /v1/elearning/assignments/download`
Securely downloads assignment question sheet or student submission file from MyBest storage.
- **Query Parameters**:
  - `id` & `file` (recommended): Parameters extracted from MyBest `/download-file-tugas` form.
  - `file_url` (optional): Direct storage URL validated against authorized BSI storage domains.

### `GET /v1/elearning/presence`
Retrieves lecture attendance status, classroom/session header information, and meeting history.
- **Query Parameter**: `token` (optional)
- **Cache TTL**: 10 minutes (600 seconds)

### `POST /v1/elearning/presence`
Submits student lecture attendance check-in ("pencet absen") for the active classroom session.
- **Query Parameter**: `token` (optional; when omitted, automatically checks in to currently active course)
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": {
      "success": true,
      "status": "Hadir",
      "matakuliah": "PENDIDIKAN PANCASILA",
      "dosen": "BDM",
      "ruang": "EL2-P1",
      "message": "Presensi mata kuliah PENDIDIKAN PANCASILA berhasil dicatat."
    }
  }
  ```

### `GET /v1/elearning/materials`
Retrieves direct download links for lecture syllabus and weekly module packages (ZIP/PDF).
- **Query Parameter**: `token` (optional)
- **Cache TTL**: 10 minutes (600 seconds)

### `GET /v1/elearning/quiz`
Retrieves active online quizzes and practice exam schedules.
- **Cache TTL**: 10 minutes (600 seconds)

### `GET /v1/elearning/quiz/questions`
Retrieves exam questions, countdown timer, CSRF token, and multiple-choice options (A, B, C, D).
- **Query Parameters**: `token` (optional), `quiz_url` (optional)

### `POST /v1/elearning/quiz/answer`
Submits option answer for a specific quiz question.
- **Payload**:
  ```json
  {
    "id_soal": "501",
    "data_jawab": "501_B",
    "csrf_token": "optional_token"
  }
  ```

### `GET /v1/elearning/grades`
Recap of assignment grades (and quiz schedules) per meeting across all active courses, or a single course when the optional `token` query parameter (from `/v1/elearning/courses`) is provided. Returns totals, graded/ungraded counts, average/max/min scores, per-course breakdown, and per-meeting rows.
- **Query Parameter**: `token` (optional)
- **Cache TTL**: 30 minutes (1800 seconds)

### `GET /v1/elearning/courses/{course_id}/grades`
Same recap scoped to one course. `course_id` accepts either the 12-char hex `id` or the course code (`kode`, e.g. `104` or `101`) from `GET /v1/elearning/courses`. Returns `404 COURSE_NOT_FOUND` when the course is unknown.
- **Cache TTL**: 30 minutes (1800 seconds)

### `GET /v1/elearning/discussions`
Lists discussion topics and lecturer tasks for a course in MyBest.
- **Query Parameter**: `token` (required, the `token_diskusi` from `/courses`)
- **Cache TTL**: 10 minutes (600 seconds)

### `GET /v1/elearning/discussions/comments`
Retrieves all comments, answers, and replies in a discussion thread.
- **Query Parameter**: `token` (required, the `token_komentar` from `/discussions`)
- **Cache TTL**: 5 minutes (300 seconds)

### `POST /v1/elearning/discussions/comments`
Posts a comment or response to a discussion thread as student.
- **Payload**:
  ```json
  {
    "token_komentar": "eyJpdi...",
    "id_chat": "24776",
    "komentar": "Tanggapan jawaban tugas saya..."
  }
  ```

### `POST /v1/elearning/discussions`
Creates a new discussion topic on a course.
- **Payload**:
  ```json
  {
    "token_course": "eyJpdi...",
    "judul": "Pertanyaan Tugas Pertemuan 4",
    "chat": "Detail pertanyaan..."
  }
  ```

### `GET /v1/elearning/profile`
Retrieves student profile name and registered email from MyBest (`/profil`).
- **Cache TTL**: 10 minutes (600 seconds)

### `GET /v1/elearning/makeups`
Retrieves registered make-up classes / schedule replacements from MyBest (`/kuliah-pengganti`).
- **Cache TTL**: 10 minutes (600 seconds)

### `GET /v1/elearning/guides`
Lists direct links to official PDF guide manuals for MyBest, Online Exam, and Quiz.

## 4. Elibrary (Library Catalog)

Public catalog search and physical book availability.

### `GET /v1/elibrary/search`
Searches the OPAC public catalog.
- **Query Parameters**:
  - `q` (required): Search keyword.
  - `opsi` (default: `buku`): Options include `buku`, `semua`, `ta`, `skripsi`, `jurnal`, `prosiding`, `ebook`.
  - `page` (default: 1): Page offset number.
- **Cache TTL**: 1 hour (3600 seconds)
- **Response Sample**:
  ```json
  {
    "success": true,
    "data": {
      "total_count": 967,
      "items": [
        {
          "id": "240688",
          "title": "Kupas tuntas algoritma clustering",
          "url": "https://elibrary.bsi.ac.id/readbook/240688/kupas-tuntas-algoritma-clustering"
        }
      ]
    },
    "cached": false
  }
  ```

### `GET /v1/elibrary/book/{book_id}`
Retrieves book metadata, classification code, publisher, ISBN, and physical shelf stock.
- **Cache TTL**: 1 hour (3600 seconds)

## 5. News & Publications

Public institutional news and scientific publications.

### `GET /v1/news`
Fetches official news posts directly from the WordPress REST API (`news.bsi.ac.id`).
- **Query Parameters**:
  - `search` (optional): Filter articles by keyword.
  - `page` (default: 1): Pagination page number.
  - `per_page` (default: 10, max: 50): Articles per page.
- **Cache TTL**: 15 minutes (900 seconds)

### `GET /v1/news/{post_id}`
Retrieves full rendered HTML content and author metadata for a specific article.

### `POST /v1/news/webhook/test`
Sends a test news publication alert to configured channels (`all`, `discord`, `telegram`, or `custom`) or explicit target parameters.
- **Query Parameters**:
  - `channel` (optional, default: `all`): Target channel to test (`all`, `discord`, `telegram`, `custom`).
  - `target_url` (optional): Override webhook URL for testing ad-hoc endpoints (Discord / Custom).
  - `telegram_bot_token` (optional): Override Telegram bot token for testing.
  - `telegram_chat_id` (optional): Override Telegram target chat ID for testing.
- **Requires Auth**: Yes (`X-API-Key`)
- **Sample Response**:
  ```json
  {
    "success": true,
    "data": {
      "message": "Pengujian broadcast channel 'all' selesai",
      "results": {
        "discord": { "configured": true, "success": true, "target": "https://discord.com/api/webhooks/..." },
        "telegram": { "configured": true, "success": true, "chat_id": "@channel_kampus" },
        "custom": { "configured": true, "success": true, "target": "https://bot-ciel.internal/api/webhook" }
      }
    },
    "cached": false
  }
  ```

### `GET /v1/repository/recent`
Retrieves recent undergraduate theses and faculty research publications from EPrints.
- **Cache TTL**: 1 hour (3600 seconds)

### `GET /v1/repository/search?q={query}`
Performs a full-text search across institutional research publications.

### `GET /v1/ejournal/journals`
Lists the catalog of 23 official UBSI peer-reviewed scientific journals.
- **Cache TTL**: 1 hour (3600 seconds)

## 6. Webhook Notification Channels

Manage personal student notification endpoints persisted in local SQLite WAL (`data/ubsi.db`).

### `GET /v1/channels`
Lists all active and inactive notification channels registered by the authenticated student (maximum 5 channels per NIM).
- **Access**: Session Token Required.
- **Sample Response**:
  ```json
  {
    "success": true,
    "data": {
      "channels": [
        {
          "id": 1,
          "type": "discord",
          "categories": ["berita-kampus"],
          "config": {
            "url": "https://discord.com/api/webhooks/..."
          },
          "is_active": true,
          "created_at": "2026-10-14 12:00:00"
        }
      ],
      "total": 1
    }
  }
  ```

### `POST /v1/channels`
Registers a new notification channel for the authenticated student. New channels start as inactive (`is_active: false`) until verified via the test endpoint.
- **Access**: Session Token Required.
- **Payload (`type: discord`)**:
  ```json
  {
    "type": "discord",
    "categories": ["berita-kampus"],
    "config": {
      "url": "https://discord.com/api/webhooks/1234567890123/abcdef..."
    }
  }
  ```
- **Payload (`type: telegram`)**:
  ```json
  {
    "type": "telegram",
    "categories": ["berita-kampus"],
    "config": {
      "bot_token": "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ",
      "chat_id": "@channel_or_id"
    }
  }
  ```

### `DELETE /v1/channels/{channel_id}`
Deletes a notification channel. Students can only delete channels registered under their own NIM.
- **Access**: Session Token Required.

### `POST /v1/channels/{channel_id}/test`
Dispatches a test notification to the designated channel. On delivery success, activates the channel (`is_active = true`).
- **Access**: Session Token Required.

### `POST /v1/channels/trigger-reminder`
Manually triggers instant event reminders (category: `matkul-besok` or `quiz-tugas`) across all active student channels.
- **Access**: Session Token Required.
- **Payload**:
  ```json
  {
    "category": "matkul-besok"
  }
  ```

## 8. Model Context Protocol (MCP) Server

UBSI API exposes an official Model Context Protocol (MCP) Server with **37 AI Agent tools** over Streamable HTTP:
- Endpoint: `https://api.muaraai.com/v1/ubsi-api/mcp`
- Authentication: `Authorization: Bearer muara_ubsi_<your_key>`
- Full reference, schema specifications, and agent prompt templates: See [docs/mcp.md](mcp.md).
